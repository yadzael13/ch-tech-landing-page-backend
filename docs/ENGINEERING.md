# Audience

Developers

# Engineering Standards

## Arquitectura

- Clean Architecture (domain / application / infrastructure / api — ver ARCHITECTURE.md y ADR-0012)
- SOLID
- DRY
- KISS
- Separation of Concerns

---

## Código

- TypeScript Strict
- Python Type Hints
- Funciones pequeñas
- Clases con una única responsabilidad

---

## Commits

Conventional Commits

Ejemplo

feat(auth): implement jwt authentication

fix(api): validate email correctly

refactor(hero): simplify animation

---

## Pull Requests

Todo PR debe incluir:

- descripción
- screenshots
- pruebas
- riesgos
