# Security Standards

## Nunca

- subir secretos al repositorio

- hardcodear credenciales

- desactivar CORS sin motivo

- confiar en datos del cliente

---

## Siempre

- validar entradas

- sanitizar datos

- usar HTTPS

- aplicar principio de mínimo privilegio

- registrar eventos importantes

- limitar intentos de autenticación

- proteger contra CSRF cuando aplique

- proteger contra XSS

- proteger contra SQL Injection

- proteger contra SSRF

- proteger contra Path Traversal
