# Reglas del Proyecto

Nunca escribir código sin una tarea.

Nunca modificar más de una responsabilidad por PR.

Toda nueva funcionalidad requiere:

- Documentación
- Tests
- Tipado
- Lint

Toda decisión importante requiere un ADR.

No se permite código muerto.

No se permite TODO sin issue asociado.

No se permite duplicación de lógica.
