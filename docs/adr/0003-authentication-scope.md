# ADR-0003

## Título

Autenticación administrativa.

## Estado

Aceptado

## Contexto

CH-TECH únicamente tendrá autenticación administrativa.

# Decisión

No se implementarán usuarios finales.

Los futuros productos SaaS tendrán su propio sistema de autenticación.

## Consecuencias

Positivas

- Fácil colaboración.
- Compatible con la mayoría de proyectos.

Negativas

- Permite reutilización del código por terceros.
