# ADR-0002

## Título

Adoptar licencia MIT.

## Estado

Aceptado

## Contexto

CH-TECH es un proyecto de portafolio y referencia técnica.

## Decisión

Se adopta MIT.

## Consecuencias

Positivas

- Fácil colaboración.
- Compatible con la mayoría de proyectos.

Negativas

- Permite reutilización del código por terceros.
